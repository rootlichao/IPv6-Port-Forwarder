# 光猫 IPv6 端口放行工具 (双栈插件版)

一个基于 PySide6 的底层光猫端口转发工具。专为开服联机打造，支持自动检测 IPv6 变动、光猫掉线重连、一键清理规则、邮件通知，采用 Telnet + 插件化底层注入方案。

## ✨ 特性
- **底层直连（零损耗）**：直接操作 `iptables` / `nftables`，完美适配对 UDP 敏感的游戏（如《像素工厂》）。
- **双栈分流**：支持物理 IPv6 与临时 IPv6 独立放行。
- **插件化架构**：内置吉比特、通用 iptables、OpenWrt fw4 等插件，可扩展。
- **控制台**：内置环境诊断提取、自定义脚本执行器，甚至支持一键重启光猫。

## 🛠️ 使用前提
1. 你的光猫必须**开启了 Telnet**。
2. 你知道光猫的**超级管理员账号和密码**。（有的设备也可以不用就能开启Telnet。比如吉比特 UNG153H）
3. 这个工具是在使移动光猫超级管理员都不支持在WEB下修改端口转发下写的。（型号吉比特 UNG153H）
## 🚀 快速开始
1. 克隆本仓库并安装依赖：
   ```bash
   pip install -r requirements.txt

2. 运行程序：
   ```bash
   python main.py

3. 在界面填入光猫信息，选择对应的适配插件，点击“启动服务”。

📦 插件说明

    吉比特 UNG153H (绝对路径版)：针对 Buildroot 系统定制，无脑直连。

    通用原生 iptables：理论上适用于绝大多数传统 Linux 光猫。

    OpenWrt 路由 (fw4)：适用于刷了 OpenWrt 的路由器。（注：没有设备并没有测试过） 
    
    原生 nftables 适配插件（实验性）：适用场景：较新的华为、中兴光猫，或底层已全面转为 nftables 的 OpenWrt 系统。（注：没有设备并没有测试过）
